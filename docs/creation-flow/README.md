# עיצוב מחדש: זרימת יצירה ואונבורדינג

מסמך אסטרטגי ומפרט מסכים למעבר מזרימת היצירה הנוכחית למסלול מהיר שמוביל לערך מיידי, עם תמונות כחלק טבעי מהתהליך — בלי חוב טכנולוגי ובלי פיצ׳רים חצי־גמורים.

| שדה | ערך |
|-----|-----|
| סטטוס | טיוטת מפרט — ממתין לאישור לפני מימוש בקוד |
| ענף מסמך | `docs/creation-flow-redesign` |
| קהל | מוצר, עיצוב, פיתוח |
| היקף | מסלול מהיר ליצירה ראשונה + חוזי נתונים + פיצול עבודה |
| מחוץ להיקף כרגע | מימוש קוד, מיזוג לפרודקשן, חיבורי פרסום לפלטפורמות |

## איך לקרוא

1. `01-as-is-to-be.md` — מה יש היום, מה רוצים, מדדים, מה נשמר
2. `02-screens-fast-path.md` — מסכים, wireframes, מיקרו־קופי, מצבי קצה
3. `03-contracts-and-anti-debt.md` — schema, רכיבים משותפים, איסורים, רשימת DEBT

## כלל ברזל

לא מתחילים פיצ׳ר במסלול הראשי בלי חוזה, בלי הסרת הנתיב הישן שיועד להחלפה, ובלי מצב סופי עקבי למשתמש. «בקרוב» ו־alert אינם פתרון ביניים מקובל.
